# Trade Card Prompt
## 交易卡片提示词模板

---

## 目的

为已进入"Trade Ready"状态的标的生成可执行的交易计划。

---

## 核心原则

> **交易卡片是最后一步，在逻辑、证据、市场、结构、风控全部确认后**
> **不提供买卖指令，只提供交易计划**

---

## 使用前提

必须满足以下条件才生成交易卡片：

- [ ] Alpha Thesis Score ≥ 70 (B 级以上)
- [ ] Market Pricing Score ≥ 60 (C 级以上)
- [ ] Trade Readiness Score ≥ 85 (Trade Ready 状态)
- [ ] Risk Governor Decision = Pass 或 Reduce Size
- [ ] 有明确催化剂时间窗口

**不满足上述条件，不生成交易卡片。**

## 交易卡片更新

### 更新触发条件

以下情况需更新交易卡片：

1. **价格变化超过 10%**
2. **关键证据变化**
3. **催化剂时间变化**
4. **技术结构显著变化**
5. **风控条件变化**
6. **每周定期复盘**

### 更新方式

- 轻微变化: 更新价格和目标价
- 中等变化: 更新交易计划
- 重大变化: 重新评估，可能作废

---

## 交易卡片失效

### 失效条件

以下情况交易卡片失效：

1. **核心逻辑被证伪**
2. **关键证据失效**
3. **催化剂落空或取消**
4. **技术结构破位**
5. **风控否决**
6. **超过有效期**

### 失效处理

- 立即停止交易
- 评估是否需要止损退出
- 分析失效原因，记录经验

## 常见错误

### 错误 1: 逻辑未确认就生成交易卡片

```
❌ 错误: Alpha Thesis Score < 70 也生成卡片
✓ 正确: 必须所有评分满足条件才生成
```

### 错误 2: 无明确止损位

```
❌ 错误: 交易卡片没有止损位
✓ 正确: 必须有明确止损位
```

### 错误 3: 过期不更新

```
❌ 错误: 交易卡片过期仍使用
✓ 正确: 过期必须重新评估
```

### 错误 4: 忽视风险提示

```
❌ 错误: 不阅读风险提示就交易
✓ 正确: 必须确认所有风险提示
```
