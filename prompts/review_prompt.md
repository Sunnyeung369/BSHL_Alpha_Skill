# Review Prompt
## 复盘提示词模板

---

## 目的

系统化复盘交易结果，提取经验教训，迭代优化系统。

---

## 核心原则

> **没有复盘，系统不会进化**
> **复盘不是追责，是学习**

---

## 复盘类型

### 类型 1: 单笔交易复盘

复盘单个标的的完整交易过程。

### 类型 2: 周期复盘

复盘一段时间（周/月/季度）的所有交易。

### 类型 3: 规则复盘

复盘特定规则的有效性。

### 类型 4: 系统复盘

复盘整个系统的运行情况。

## 复盘频率

### 单笔交易复盘

- **触发**: 交易结束后立即复盘
- **深度**: 详细复盘
- **产出**: 交易复盘报告

### 周复盘

- **触发**: 每周末
- **深度**: 中等
- **产出**: 周复盘报告

### 月复盘

- **触发**: 每月末
- **深度**: 详细
- **产出**: 月复盘报告 + 规则验证

### 季度复盘

- **触发**: 每季度末
- **深度**: 全面
- **产出**: 季度复盘 + 系统复盘

## 常见错误

### 错误 1: 不复盘

```
❌ 错误: 交易结束就结束，不复盘
✓ 正确: 每笔交易都复盘
```

### 错误 2: 复盘变成追责

```
❌ 错误: 复盘时责怪自己
✓ 正确: 复盘是学习，不是追责
```

### 错误 3: 不记录复盘结果

```
❌ 错误: 复盘但不记录
✓ 正确: 所有复盘都要记录
```

### 错误 4: 不应用复盘结果

```
❌ 错误: 复盘但不改进行为
✓ 正确: 复盘结果必须应用到后续交易
```
