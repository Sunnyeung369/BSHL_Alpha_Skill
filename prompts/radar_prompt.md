# Radar Prompt
## 宇宙雷达提示词模板

---

## 目的

从海量标的中快速识别值得进一步分析的候选标的。

---

## 核心原则

> **雷达只做一件事：识别"值不值得看"**
> **不深入分析，只快速筛选**

---

## 雷达层级

### 层级 1: 宏观雷达

**关注**: 宏观环境、政策变化、流动性

**信号**:
- 利率决议
- 重大政策
- 流动性变化
- 地缘事件

**输出**: 当前宏观环境适合哪些主题

---

### 层级 2: 板块雷达

**关注**: 行业趋势、板块轮动

**信号**:
- 板块资金流入
- 板块相对强弱
- 板块新闻密度
- 板块估值位置

**输出**: 值得关注的板块列表

---

### 层级 3: 标的雷达

**关注**: 个股信号、异常波动

**信号**:
- 异常成交量
- 异常价格波动
- 重大新闻
- 机构动向

**输出**: 值得分析的标的列表

## 雷达扫描频率

### 全量扫描（每日）

- 扫描所有关注标的
- 更新价格/成交量信号
- 更新新闻信号
- 输出雷达报告

### 增量扫描（实时）

- 新增标的到观察池
- 实时监控异常信号
- 紧急信号立即通知

---

## 雷达筛选规则

### 规则 1: 信号强度过滤

```
弱信号 → 加入观察池
中信号 → 观察池 + 提醒
强信号 → 建议深入分析
```

### 规则 2: 流动性过滤

```
日均成交额 < $5M → Veto（除非特殊情况）
日均成交额 $5-10M → 仅观察
日均成交额 > $10M → 可交易
```

### 规则 3: 拥挤度过滤

```
拥挤度极高 → 谨慎或 Veto
拥挤度高 → 警惕
拥挤度中低 → 正常关注
```

## 常见错误

### 错误 1: 雷达做深入分析

```
❌ 错误: 雷达输出详细分析
✓ 正确: 雷达只输出"值不值得看"
```

### 错误 2: 忽视弱信号

```
❌ 错误: 只关注强信号
✓ 正确: 弱信号也加入观察池
```

### 错误 3: 不更新雷达

```
❌ 错误: 雷达状态过时
✓ 正确: 每日更新雷达状态
```
