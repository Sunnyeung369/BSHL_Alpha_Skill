# Market Regime Gate
## 市场状态门控参考规则

---

## 为什么需要市场状态过滤

同一个好逻辑，在不同市场状态下结果完全不同。

**示例**:
```
好逻辑 + Risk On 市场 = 可能大涨
好逻辑 + Risk Off 市场 = 可能不涨或下跌
```

> **没有市场状态过滤的投研系统，迟早会在好逻辑里亏钱。**

## 市场状态维度

### 1. 大盘趋势

| 状态 | 特征 | 交易策略 |
|------|------|----------|
| 上升 | 持续创新高 | 提高进攻权重 |
| 震荡 | 区间波动 | 只做强势突破 |
| 下降 | 持续创新低 | 降低仓位或只观察 |

**判断依据**:
- 主要指数趋势（SPX, NDX, HSI, etc.）
- 移动均线排列
- 高低点结构

---

### 2. 板块趋势

| 状态 | 特征 | 交易策略 |
|------|------|----------|
| 强势 | 跑赢大盘 | 优先配置 |
| 跟随 | 与大盘同步 | 正常配置 |
| 弱势 | 跑输大盘 | 避免配置 |

**判断依据**:
- 板块 vs 大盘相对强弱
- 板块指数趋势
| 资金流向 | 流入 | 流入 |
|  | 流出 | 流出 |
|  | 平衡 | 平衡 |

## 市场状态输出

### 综合状态

| 状态 | 含义 | 交易策略 |
|------|------|----------|
| Risk On | 可提高进攻权重 | 增加仓位，追强势突破 |
| Neutral | 只做强逻辑强结构 | 只做高质量机会 |
| Risk Off | 降仓或只观察 | 降低仓位或空仓 |
| Crowded | 防止高位接盘 | 等待回踩 |
| Rotation | 注意板块切换 | 关注新热点 |
| Breakdown | 风控优先 | 降低仓位，保护本金 |

## 使用规则

### 规则 1: 市场状态优先

```
即使 Alpha Thesis 很强，如果市场状态是 Risk Off，
也要降低交易状态或降低仓位。
```

### 规则 2: 拥挤度降级

```
即使 Alpha Thesis 很强，如果拥挤度过高，
也要降级为 Wait Pullback 或降低仓位。
```

### 规则 3: 动态调整

```
市场状态是动态的，需要定期检查。
当市场状态发生变化时，需要重新评估所有持仓。
```
