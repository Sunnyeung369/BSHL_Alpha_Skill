# Technical Structure Rules
## BSHL K线结构参考规则

---

## 核心原则

> **投研只决定"值不值得看"，K线结构决定"能不能动手"。**

---

## 必须检查的维度

### 1. 母周期方向

| 状态 | 特征 | 交易策略 |
|------|------|----------|
| 上升 | 高点低点不断抬高 | 顺势做多 |
| 震荡 | 高点低点区间波动 | 突破后跟随 |
| 下降 | 高点低点不断降低 | 只做反弹或回避 |

**判断依据**:
- 周线/月线高低点结构
- 移动均线排列
- 趋势线

### 2. 子周期位置

| 位置 | 特征 | 交易策略 |
|------|------|----------|
| 筑底 | 横盘整理，波动收敛 | 等待突破 |
| 突破 | 突破关键阻力 | 观察确认 |
| 加速 | 快速上涨 | 谨慎追高 |
| 回踩 | 上涨后回调 | 寻找入场点 |
| 过热 | 远离均线，成交量萎缩 | 警惕回调 |
| 破位 | 跌破关键支撑 | 避免接飞刀 |

### 3. 高低结构

**关键高低点识别**:
- 重要支撑位
- 重要阻力位
- 前期高点/低点
- 整数关口

**规则**: 价格在关键高低点附近时，观察反应更可靠。

### 4. 突破确认

**有效突破的条件**:
- [ ] 收盘价突破（非盘中）
- [ ] 成交量放大
- [ ] 突破后站稳（不立即回落）

**假突破信号**:
- 突破但成交量萎缩
- 突破后立即回落
- 尾盘回落

### 5. 回踩质量

**健康回踩的特征**:
- [ ] 回踩到支撑位附近
- [ ] 成交量萎缩
- [ ] 不跌破关键支撑
- [ ] 重新放量上涨

**不健康回踩**:
- 跌破支撑位
- 成交量放大
- 无法反弹

### 6. 成交量确认

| 价格 | 成交量 | 含义 |
|------|--------|------|
| 上涨 | 放量 | 确认上涨 |
| 上涨 | 缩量 | 力量不足 |
| 下跌 | 放量 | 确认下跌 |
| 下跌 | 缩量 | 可能企稳 |

### 7. 相对强弱

| 强弱 | 特征 | 交易策略 |
|------|------|----------|
| 跑赢大盘/板块 | 相对强度线向上 | 优先配置 |
| 跑输大盘/板块 | 相对强度线向下 | 避免配置 |

### 8. ATR 波动

| ATR 水平 | 风险 | 交易策略 |
|----------|------|----------|
| 过高 | 止损距离过大 | 降低仓位或回避 |
| 正常 | 止损可控 | 正常交易 |
| 过低 | 波动收敛 | 等待突破 |

### 9. 止损位清晰度

**好的止损位**:
- 支撑位下方
- 关键低点下方
- 技术位明确
- 距离合理（< 8%）

**差的止损位**:
- 下方无明显支撑
- 距离过远（> 10%）
- 技术位模糊

### 10. 盈亏比

**建议盈亏比**: ≥ 2:1

```
盈亏比 = (目标价 - 入场价) / (入场价 - 止损价)
```

| 盈亏比 | 评价 | 交易策略 |
|--------|------|----------|
| < 1:1 | 不佳 | 不交易 |
| 1:1 - 2:1 | 一般 | 谨慎交易 |
| > 2:1 | 优秀 | 可交易 |

## 交易结构状态

| 结构 | 特征 | 交易策略 |
|------|------|----------|
| Base Building | 横盘整理，波动收敛 | 等待突破 |
| Breakout Watch | 接近关键阻力 | 准备突破 |
| Confirmed Breakout | 有效突破 | 可跟随 |
| Pullback Entry Zone | 回踩支撑区 | 寻找入场 |
| Exhaustion | 远离均线，放量 | 警惕回调 |
| Breakdown | 跌破支撑 | 避免接飞刀 |
| No Trade | 无明确结构 | 不交易 |

---

## 硬规则

### 规则 1: 收盘确认

```
没有收盘确认，不升级交易状态。
盘中突破不代表有效突破。
```

### 规则 2: 止损优先

```
没有清晰止损位，不进入执行准备。
止损距离过大，降低仓位或否决。
```

### 规则 3: 结构优先

```
即使逻辑很好，如果 K 线结构不好，也不交易。
等结构改善再考虑。
```

### 规则 4: 成交量确认

```
没有成交量配合的突破，视为假突破。
上涨必须放量，回踩应该缩量。
```

## 检查清单

### 每次交易前检查

- [ ] 母周期方向
- [ ] 子周期位置
- [ ] 关键高低点识别
- [ ] 突破是否有效
- [ ] 回踩是否健康
- [ ] 成交量是否确认
- [ ] 相对强弱
- [ ] ATR 波动
- [ ] 止损位清晰
- [ ] 盈亏比合理

## 常见错误

### 错误 1: 追高

```
❌ 错误: 标的已经大幅上涨，远离均线，仍然追入
✓ 正确: 等待回踩确认或更好的入场点
```

### 错误 2: 接飞刀

```
❌ 错误: 标的正在暴跌，无支撑位就买入
✓ 正确: 等待企稳信号和支撑位确认
```

### 错误 3: 盘中突破就入场

```
❌ 错误: 盘中突破立即入场
✓ 正确: 等待收盘确认突破有效
```

### 错误 4: 忽视成交量

```
❌ 错误: 只看价格，不看成交量
✓ 正确: 价格 + 成交量一起判断
```
