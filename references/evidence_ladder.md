# Evidence Ladder
## 证据阶梯参考规则

---

## 证据强度分级

### Strong Evidence（强证据）

**定义**: 来自官方或权威来源，具有高可信度的证据。

**来源类型**:
- 公司官方文件（10-K, 10-Q, 8-K）
- 财报电话会议记录（Transcript）
- 公司新闻稿（Press Release）
- 官方公告
- 监管文件
- 行业权威报告

**权重**: 可以单独支持交易准备决策

**示例**:
```
强证据:
- NVIDIA 2024 Q2 财报: 数据中心收入同比增长 171%
- CEO 在财报电话会议: "AI 需求强劲，供给仍然紧张"
- 公司 8-K 文件: 宣布与某大型云服务商的三年合作协议
```

---

### Medium Evidence（中证据）

**定义**: 来自权威渠道，但非一手来源的证据。

**来源类型**:
- 权威媒体报道（WSJ, Bloomberg, Reuters）
- 行业协会声明
- 管理层公开讲话（非官方文件）
- 有数据支撑的研究报告
- 知名分析师报告

**权重**: 可以辅助判断，但不能单独支持交易准备

**示例**:
```
中证据:
- Bloomberg 报道: 数据中心运营商表示电力需求激增
- 某行业协会报告: 预计 2025 年 AI 数据中心耗电将增长 200%
- 知名分析师报告: 上调目标价，理由是 AI 需求强劲
```

---

### Weak Evidence（弱证据）

**定义**: 来自非权威渠道，或缺乏具体数据的证据。

**来源类型**:
- 社媒讨论（Twitter, Reddit, Discord）
- 分析师推测
- 市场传闻
- 无具体来源的消息
- 个人观点

**权重**: 只能提出假设，不能单独支持任何决策

**示例**:
```
弱证据:
- Twitter 讨论: 很多人讨论 AI 电力短缺
- 某分析师在电视上的"推测"
- 市场传闻: 某公司可能获得大订单
```

---

### Stale Evidence（过期证据）

**定义**: 曾经有效但已失去时效性的证据。

**判断标准**:
- 超过 6 个月的数据（快速变化的行业）
- 超过 12 个月的数据（传统行业）
- 被后续事件推翻的判断
- 已过期的催化剂

**权重**: 不能用于当前决策

**示例**:
```
过期证据:
- 2023 年的报告: 预计 2024 年 AI 需求将大幅增长（现在已经 2025 年）
- 去年的判断: "XX 公司即将受益于 XX 趋势"（趋势已经兑现或失败）
```

## 证据使用规则

### 规则 1: 强证据可以提高置信度

强证据可以直接提高判断的置信度。

```
强证据 + 强证据 = 高置信度
强证据 + 中证据 = 中高置信度
```

### 规则 2: 弱证据只能提出假设

弱证据不能单独支持任何决策，只能提出需要验证的假设。

```
弱证据 → 提出"需要验证"的假设
不能用弱证据直接升级交易状态
```

### 规则 3: 证据必须溯源

每条证据必须标注：
- 来源类型
- 来源日期
- 证据强度

### 规则 4: 证据有保质期

证据会随时间失效：
- 快速变化行业（Crypto, AI）: 3-6 个月
- 传统行业: 12 个月
- 催化剂相关: 催化剂兑现后即失效

### 规则 5: 相反证据必须考虑

如果存在相反的强证据，必须调整判断：

```
强证据支持 + 强证据反对 → 结论不确定
需要寻找决定性证据或等待更多数据
```

## 证据检查清单

### 新证据检查

收到新证据时，检查：

| 检查项 | 问题 |
|--------|------|
| 来源 | 证据来自哪里？ |
| 时效 | 证据是什么时候的？ |
| 强度 | 证据是强/中/弱？ |
| 相关性 | 证据与判断直接相关吗？ |
| 独立性 | 证据是否独立于其他证据？ |

### 证据冲突处理

当存在证据冲突时：

1. **强 vs 弱**: 强证据优先
2. **新 vs 旧**: 新证据优先（同一强度）
3. **官方 vs 非官方**: 官方优先
4. **数据 vs 观点**: 数据优先

## 常见错误

### 错误 1: 用弱证据做关键判断

```
❌ 错误: Twitter 有人说 XX 公司订单爆满，所以买入
✓ 正确: Twitter 讨论提出假设"XX 公司可能受益"，需要官方文件验证
```

### 错误 2: 忽略证据时效

```
❌ 错误: 用 1 年前的报告判断当前 AI 趋势
✓ 正确: AI 行业变化快，6 个月前的报告可能已过时
```

### 错误 3: 证据不溯源

```
❌ 错误: "有消息说..."
✓ 正确: "根据 XX 公司 8-K 文件..."
```

## 证据收集优先级

### 优先级 1: 官方一手数据

- 公司财报
- 公司公告
- 监管文件

### 优先级 2: 权威二手数据

- 权威媒体报道
- 行业报告
- 知名研究报告

### 优先级 3: 市场信号

- 价格走势
- 成交量
- 期权数据

### 优先级 4: 社媒情绪

- 社媒讨论
- 情绪指标
- 热度指标
