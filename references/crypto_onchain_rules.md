# Crypto On-chain Rules
## Crypto 链上规则参考

---

## 核心原则

> **Crypto 特有: 链上数据 > 传统分析**
> **链上信号强 ≠ 价格一定涨**

---

## 链上指标体系

### 指标 1: 活跃地址数

**定义**: 一定时间内有交易的地址数量

**数据来源**: 链上数据直接统计

**判断标准**:

| 趋势 | 解读 | 价格含义 |
|-----|------|----------|
| 持续上升 | 用户活跃增加 | 支撑价格上涨 |
| 高位回落 | 用户活跃下降 | 价格承压 |
| 长期下降 | 用户流失 | 长期利空 |
| 突然激增 | 可能是操纵 | 谨慎解读 |

**注意事项**:
- 区分真实用户和 Sybil 攻击
- 结合交易量看质量
- 区分冷钱包和热钱包

---

### 指标 2: 大额转账

**定义**: 单笔转账超过一定阈值（如 100 BTC）

**数据来源**: 链上交易记录

**判断标准**:

| 转账类型 | 解读 | 价格含义 |
|---------|------|----------|
| 交易所流入增加 | 卖压增加 | 价格承压 |
| 交易所流出增加 | 持币意愿强 | 支撑价格 |
| 冷钱包转账增加 | 长期持有 | 中性偏多 |
| 大户集中转账 | 可能操纵 | 谨慎解读 |

**注意事项**:
- 区分交易所地址
- 区分用户类型
- 结合价格走势看意图

---

### 指标 3: HODLer 行为

**定义**: 长期持有者的行为模式

**关键指标**:
- **长期持有供应量**: 持有 > 1 年未动的币量
- **损耗币天数**: 币被移动时累积的币天数
- **实现市值**: 最后一次移动时的币价值

**判断标准**:

| 指标 | 强势信号 | 弱势信号 |
|-----|---------|---------|
| 长期持有供应量 | 增加 | 减少 |
| 损耗币天数 | 高峰 | 低谷 |
| 实现市值 | 高位增长 | 低位下降 |

**价格含义**:
- HODLer 增加表示长期信心
- HODLer 减少表示获利了结

---

### 指标 4: 交易费率

**定义**: 链上交易支付的 Gas 费用

**数据来源**: 链上交易记录

**判断标准**:

| 费率水平 | 解读 | 价格含义 |
|---------|------|----------|
| 极高 (> $100) | 网络拥堵，需求强 | 可能顶部 |
| 高 ($50-100) | 活跃度高 | 支撑价格 |
| 中等 ($10-50) | 正常活跃 | 中性 |
| 低 (< $10) | 活跃度低 | 可能底部 |

**注意事项**:
- ETH 和 L2 费率不同
- 结合链上活动看质量
- 区分正常交易和 NFT mint

---

### 指标 5: 矿工行为

**定义**: 矿工的卖出行为

**关键指标**:
- **矿工余额**: 矿池钱包余额
- **矿工流出**: 矿工钱包到交易所的转账
- **算力分布**: 矿工集中度

**判断标准**:

| 行为 | 解读 | 价格含义 |
|-----|------|----------|
| 矿工持续流出 | 卖压增加 | 价格承压 |
| 矿工余额增加 | 矿工囤币 | 支撑价格 |
| 算力集中 | 风险增加 | 谨慎 |
| 算力分散 | 风险降低 | 积极 |

---

### 指标 6: 稳定币流动

**定义**: 稳定币（USDT, USDC, DAI）的流入流出

**关键指标**:
- **交易所稳定币余额**: 交易所内稳定币量
- **稳定币溢价**: 稳定币与美元的价差
- **铸造/销毁量**: 新铸造或销毁的稳定币

**判断标准**:

| 指标 | 强势信号 | 弱势信号 |
|-----|---------|---------|
| 交易所稳定币余额 | 增加 | 减少 |
| 稳定币溢价 | 正溢价 | 负溢价 |
| 铸造量 | 增加 | 减少 |

**价格含义**:
- 稳定币流入 = 买入潜力
- 稳定币流出 = 卖出压力

## 链上信号陷阱

### 陷阱 1: 链上信号强但价格不涨

**原因**:
- 市场已提前定价
- 宏观环境不利
- 板块轮动
- 技术阻力位

**应对**:
- 综合多维度分析
- 不要单独依赖链上数据
- 等待价格确认

---

### 陷阱 2: 链上数据被操纵

**操纵方式**:
- 交易所自交易
- Wash Trading（对倒）
- Sybil 攻击（伪造账户）
- 大户分拆交易

**识别方法**:
- 交易模式异常
- 地址关联分析
- 与交易所数据对比
- 与链下数据交叉验证

---

### 陷阱 3: 链上信号滞后

**原因**:
- 数据处理延迟
- 指标计算周期
- 市场快速变化

**应对**:
- 使用实时数据源
- 结合价格走势
- 设置预警阈值

## 链上 + 传统分析框架

### 综合分析模板

```
Layer 1: 链上基础数据
  ├─ 活跃地址数
  ├─ 交易量
  ├─ 大额转账
  └─ 矿工行为

Layer 2: 链上衍生指标
  ├─ HODLer 行为
  ├─ 稳定币流动
  ├─ 实现市值
  └─ MVRV 比率

Layer 3: 传统市场数据
  ├─ 价格走势
  ├─ 成交量
  ├─ 期权数据
  └─ 资金流向

Layer 4: 宏观环境
  ├─ 流动性环境
  ├─ 监管环境
  └─ 市场情绪
```

## Crypto 特有风险

### 风险 1: 监管风险

**特征**:
- 政策突变
- 交易所被查
- 项目被禁

**应对**:
- 关注监管动向
- 分散地域风险
- 选择合规交易所

---

### 风险 2: 技术风险

**特征**:
- 智能合约漏洞
- 链遭到攻击
- 硬分叉争议

**应对**:
- 选择成熟链
- 检查合约审计
- 关注技术社区

---

### 风险 3: 流动性风险

**特征**:
- 交易所流动性不足
- 深度不足
- 滑点过大

**应对**:
- 检查流动性
- 使用限价单
- 分批交易

## 常见错误

### 错误 1: 只看链上数据

```
❌ 错误: 链上信号强就买入
✓ 正确: 综合链上 + 传统 + 宏观分析
```

### 错误 2: 忽视宏观环境

```
❌ 错误: 宏观环境差也买
✓ 正确: 宏观环境差时，链上信号再强也要谨慎
```

### 错误 3: 不验证数据源

```
❌ 错误: 信任单一数据源
✓ 正确: 多数据源交叉验证
```

### 错误 4: 忽视流动性

```
❌ 错误: 买入流动性差的 Altcoin
✓ 正确: 检查流动性，小仓位或 Veto
```
