# Valuation Sanity Check
## 估值合理性检查参考规则

---

## 核心原则

> **好逻辑 + 好价格 = 好投资**
> **好逻辑 + 坏价格 = 等待**
> **坏逻辑 + 任何价格 = 不投资**

---

## 估值框架

### 估值三问

1. **当前估值是否合理？**
   - 与历史比较
   - 与同行比较
   - 与增长预期匹配

2. **估值是否已透支未来增长？**
   - 远期 PE 已包含多少年增长
   - PS 是否隐含过高收入增长
   - PB 是否隐含过高 ROE

3. **是否存在估值错配？**
   - 市场低估增长潜力
   - 市场高估风险
   - 市场误解商业模式

---

## 估值方法

### 方法 1: PE 估值

**适用**: 盈利稳定的成熟公司

**公式**: `PE = 股价 / 每股收益 (EPS)`

**判断标准**:

| PE 水平 | 解读 | 投资含义 |
|---------|------|----------|
| 低于历史 25 分位 | 被低估 | 可能存在机会 |
| 历史 25-75 分位 | 合理区间 | 需要结合其他因素 |
| 高于历史 75 分位 | 高估值 | 需要强增长支撑 |

**注意事项**:
- 周期股 PE 低时可能是高估（盈利顶峰）
- 成长股 PE 高可能是合理（增长预期）
- 负收益无法使用 PE

---

### 方法 2: PEG 估值

**适用**: 高增长公司

**公式**: `PEG = PE / 增长率`

**判断标准**:

| PEG 水平 | 解读 | 投资含义 |
|---------|------|----------|
| < 0.8 | 低估 | 值得关注 |
| 0.8 - 1.2 | 合理 | 可考虑 |
| 1.2 - 2.0 | 偏高 | 需要强理由 |
| > 2.0 | 高估 | 谨慎追高 |

**注意事项**:
- 增长率必须可持续
- 高增长不能长期维持（均值回归）
- 不同行业 PEG 标准不同

---

### 方法 3: PS 估值

**适用**: 未盈利或高增长公司

**公式**: `PS = 股价 / 每股销售额`

**判断标准**:

| PS 水平 | 解读 | 投资含义 |
|---------|------|----------|
| < 2x | 低估值 | 可能存在机会 |
| 2x - 5x | 合理区间 | 需结合利润率 |
| 5x - 10x | 偏高 | 需要高增长 |
| > 10x | 高估值 | 风险较大 |

**注意事项**:
- 需要结合利润率评估
- 高利润率可支持更高 PS
- 需要关注收入质量

---

### 方法 4: PB 估值

**适用**: 资产密集型、金融股

**公式**: `PB = 股价 / 每股净资产`

**判断标准**:

| PB 水平 | 解读 | 投资含义 |
|---------|------|----------|
| < 1.0 | 低估值 | 可能存在机会 |
| 1.0 - 3.0 | 合理区间 | 需结合 ROE |
| 3.0 - 5.0 | 偏高 | 需要高 ROE |
| > 5.0 | 高估值 | 风险较大 |

**注意事项**:
- 需要结合 ROE 评估
- 高 ROE 可支持更高 PB
- 金融股需要调整资产质量

---

### 方法 5: EV/EBITDA 估值

**适用**: 资本结构差异大的公司

**公式**: `EV/EBITDA = (市值 + 净债务) / EBITDA`

**判断标准**:

| EV/EBITDA 水平 | 解读 | 投资含义 |
|---------------|------|----------|
| < 8x | 低估值 | 值得关注 |
| 8x - 12x | 合理区间 | 可考虑 |
| 12x - 16x | 偏高 | 需要理由 |
| > 16x | 高估值 | 谨慎追高 |

**注意事项**:
- 跨行业比较更准确
- 需要考虑折旧摊销政策
- 资本密集行业使用

---

### 方法 6: DCF 估值

**适用**: 现金流稳定可预测的公司

**公式**: `企业价值 = Σ(自由现金流 / (1+WACC)^t)`

**关键假设**:
- 收入增长率
- 利润率
- 资本支出
- WACC（加权平均资本成本）
- 永续增长率

**注意事项**:
- 对假设敏感度高
- 垃圾进，垃圾出
- 需要情景分析

## 估值陷阱

### 陷阱 1: 价值陷阱

**定义**: PE 低但基本面恶化

**特征**:
- PE 处于历史低位
- 但盈利下降趋势
- 行业衰退或竞争加剧
- 削减成本维持利润

**应对**: 检查盈利质量和可持续性

---

### 陷阱 2: 成长陷阱

**定义**: 高增长但估值透支

**特征**:
- 历史高增长
- 高 PE 或高 PS
- 但增长即将放缓
- 竞争加剧或市场饱和

**应对**: 评估增长可持续性和估值匹配度

---

### 陷阱 3: 周期陷阱

**定义**: 周期顶峰时看起来便宜

**特征**:
- PE 低（盈利顶峰）
- 但周期即将下行
- 价格已反映最好情景
- 供给即将增加

**应对**: 识别周期位置，避免顶峰买入

---

### 陷阱 4: 资产质量陷阱

**定义**: PB 低但资产质量差

**特征**:
- PB < 1
- 但资产有水分
- 商誉减值风险
- 存货/应收账款风险

**应对**: 检查资产质量和真实性

## 估值合理性检查清单

### 检查项 1: 历史比较

- [ ] 当前 PE vs 历史 5 年 PE 分位
- [ ] 当前 PS vs 历史 5 年 PS 分位
- [ ] 当前 PB vs 历史 5 年 PB 分位
- [ ] 当前 EV/EBITDA vs 历史 5 年分位

### 检查项 2: 同行比较

- [ ] 与同行 PE 比较
- [ ] 与同行 PS 比较
- [ ] 与同行 PB 比较
- [ ] 与同行 EV/EBITDA 比较

### 检查项 3: 增长匹配

- [ ] 当前增长 vs 估值隐含增长
- [ ] 未来增长预期是否可实现
- [ ] 增长可持续性如何
- [ ] 增长质量如何（有机 vs 外延）

### 检查项 4: 风险调整

- [ ] 高风险是否需要更高安全边际
- [ ] 行业风险是否反映在估值
- [ ] 公司特定风险是否考虑
- [ ] 流动性风险是否考虑

## 估值决策树

```
开始
  │
  ├─ 盈利稳定？
  │   ├─ 是 → 使用 PE
  │   │        ├─ PE < 历史 25 分位 → 低估
  │   │        ├─ PE 25-75 分位 → 合理
  │   │        └─ PE > 75 分位 → 高估
  │   └─ 否 → 检查 PS
  │            ├─ PS < 2x → 可能低估
  │            ├─ PS 2-5x → 需结合利润率
  │            └─ PS > 10x → 高估
  │
  ├─ 高增长？
  │   ├─ 是 → 检查 PEG
  │   │        ├─ PEG < 1 → 低估
  │   │        ├─ PEG 1-2 → 合理
  │   │        └─ PEG > 2 → 高估
  │   └─ 否 → 使用 PE/PS
  │
  └─ 金融/周期？
      ├─ 是 → 使用 PB
      │        ├─ PB < 1 → 可能低估
      │        ├─ PB 1-3 → 需结合 ROE
      │        └─ PB > 5 → 高估
      └─ 否 → 使用 PE
```

## 常见错误

### 错误 1: 只看 PE

```
❌ 错误: PE 低就是低估
✓ 正确: PE 低可能是盈利顶峰（周期陷阱）
```

### 错误 2: 忽视增长

```
❌ 错误: 高 PE 一定是高估
✓ 正确: 高 PE 可能是高增长合理反映
```

### 错误 3: 机械比较

```
❌ 错误: PE 20 就比 PE 30 便宜
✓ 正确: 需要考虑增长率和风险
```

### 错误 4: 忽视利率环境

```
❌ 错误: 不考虑利率环境
✓ 正确: 低利率支持高估值，高利率压制估值
```
