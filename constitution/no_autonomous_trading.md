# No Autonomous Trading
## BSHL Alpha Skill 非自主交易声明

---

## 核心声明

**BSHL Alpha Skill 不执行任何形式的自主交易。**

本系统的设计目的是：
- 发现投研机会
- 评估交易准备状态
- 提供风险判断
- 沉淀复盘知识

**所有交易决策必须由用户人工确认。**

---

## 系统边界

### 系统做的事

| 功能 | 说明 |
|------|------|
| 雷达扫描 | 发现潜在机会 |
| 逻辑拆解 | 分析投研假设 |
| 证据评估 | 验证逻辑强度 |

| 功能 | 说明 |
|------|------|
| 自动下单 | ❌ 不执行 |
| 自动止损 | ❌ 不执行 |
| 自动调仓 | ❌ 不执行 |
| 自动融资融券 | ❌ 不执行 |
| 自动期权行权 | ❌ 不执行 |

## 确认流程

### 标准确认流程

```
┌─────────────────────────────────────┐
│  系统分析标的                       │
│  ↓                                  │
│  输出: Trade Ready                  │
│  ↓                                  │
│  [等待用户确认]                     │
│  ↓                                  │
│  用户: "确认" / "取消" / "修改"     │
│  ↓                                  │
│  如确认 → 进入执行准备              │
│  如取消 → 进入观察池                │
└─────────────────────────────────────┘
```

## 风控否决权

### Risk Governor 最高权限

即使系统输出"Trade Ready"，Risk Governor 仍可一票否决。

**否决条件：**
- 流动性不足
- 波动过大
- 证据质量太弱
- 社媒热度过度拥挤
- 财报前风险过高
- 重大监管不确定

**否决即停止：**
```
系统输出: Trade Ready
→ Risk Governor 检查
→ 触发否决条件
→ 最终输出: Veto
→ 流程停止，不进入确认环节
```

### 用户否决权

用户随时可以否决系统建议：

```
系统输出: Trade Ready
→ 用户: Veto
→ 流程停止
```

## 紧急停止机制

### 用户发起的紧急停止

用户可以随时发送以下命令停止流程：

- "停止"
- "Veto"
- "取消"
- "不要"
- "No"

### 系统响应

收到紧急停止命令后：
1. 立即停止当前分析
2. 输出当前已保存的状态
3. 等待用户下一步指示

---

## 执行与观察分离

### Trade Ready ≠ 立即执行

"Trade Ready"只表示：
- 逻辑成立
- 市场环境合适
- K线结构健康
- 风控检查通过

**但绝不表示立即执行。**

执行前用户还需确认：
- 具体入场价位
- 具体止损价位
- 具体仓位大小
- 具体执行时间

## 不可绕过的原则

### 三条不可绕过的原则

1. **风控否决不可绕过**
   - Risk Governor 说了 Veto 就是 Veto
   - 系统无权限建议用户绕过风控

2. **用户确认不可绕过**
   - 没有用户确认，不进入执行准备
   - 系统不能自动替用户确认

3. **日志记录不可绕过**
   - 所有决策必须记录
   - 没有日志的系统视为不完整
