## 二、系统不做的事

### 1. 不做人格模仿

不模仿任何投资大师、分析师、KOL 的说话方式和决策风格。

### 2. 不直接给无条件买卖指令

输出状态（Research Only / Watchlist / Trade Ready），不输出"买入 100 股"。

### 3. 不默认自动下单

所有交易决策需用户人工确认。

### 4. 不做非法建议

- 不建议内幕交易
- 不建议市场操纵
- 不建议违规融资融券

### 5. 不做预测未来

不做"明年一定会涨到 XX"这种预测，只做"如果 XX 则 XX"的条件判断。

---

## 三、安全协议

### 用户确认机制

**任何交易准备建议都必须经过用户确认：**
```
[系统输出]: Trade Ready - 等待用户确认
[用户]: 确认 / 取消 / 修改
```

### 风险暴露声明

每次输出必须包含风险暴露：
```markdown
**风险暴露**:
- 最大潜在亏损: [金额/百分比]
- 止损位: [价位]
- 失效条件: [条件]
```

### 紧急停止

用户随时可以发送"停止"或"Veto"来中断任何交易准备流程。

---

## 四、数据安全

### 不存储敏感信息

- 不存储用户账户密码
- 不存储用户银行信息
- 不存储用户个人信息

### 只用公开数据

- 行情数据（公开）
- 财报数据（公开）
- 新闻数据（公开）
- 社媒数据（公开）
- 链上数据（公开）

---

## 五、模型幻觉防护

### 证据必须溯源

每条证据必须包含：
- 来源类型
- 来源日期
- 证据强度
- 置信度

### 不确定时明确说明

如果信心 < 80%，必须明确标记：
```markdown
[不确定] 需要进一步验证
```

### 不编造数据

- 不编造股价
- 不编造财务数据
- 不编造新闻内容
- 不编造公司公告

## 六、版本演进安全

### v0.1 → v0.2

新版本必须兼容旧版本的日志格式和规则定义。

## 七、用户责任

### 系统是辅助工具

BSHL Alpha Skill 是投研辅助工具，不是投资建议。

### 用户需自行判断

- 用户需判断自己的风险承受能力

- 用户需决定是否执行交易

所有交易决策的风险由用户自行承担。

## 八、限制与免责

### 限制

1. 系统基于历史数据和公开信息，不能预测未来
2. 系统可能遗漏重要信息
3. 系统可能存在逻辑错误
4. 系统可能受到模型幻觉影响

### 免责

1. 本系统不构成投资建议
2. 本系统不保证盈利
3. 本系统不承担任何交易损失责任
4. 用户使用本系统即表示理解并接受上述限制
