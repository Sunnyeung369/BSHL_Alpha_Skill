# Daily Market Radar
## 每日市场雷达工作流

---

## 工作流目的

扫描指定方向，发现值得进入观察池的标的。

---

## 输入格式

```
今天帮我扫描 [方向1, 方向2, ...]，有哪些值得进入观察池的标的？
```

**支持的方向：**
- AI 产业链
- 半导体
- 能源与电力
- 核能
- Crypto（RWA, DePIN, 稳定币）
- 机器人
- 国防科技
- 生物科技
- 消费科技

---

## 处理流程

### 第 1 步：方向展开

将用户输入的方向展开成具体的产业链环节。

**示例：**
```
输入: AI 电力
展开:
- 数据中心
- 电网设备
- 变压器
- 核电
- 储能
```

### 第 2 步：催化剂识别

识别每个环节的潜在催化剂：

| 催化剂类型 | 说明 |
|-----------|------|
| 政策变化 | 监管、补贴、关税 |
| 技术突破 | 新技术、新应用 |
| 供需变化 | 需求增加、供给受限 |
| 事件驱动 | 财报、会议、发布 |

### 第 3 步：受益链映射

识别每个催化剂的受益公司类型：

| 受益类型 | 说明 |
|---------|------|
| 直接受益 | 产品直接受益 |
| 间接受益 | 供应链受益 |
| 影子股 | 概念相关但实质有限 |

### 第 4 步：候选标的选择

根据受益类型选择候选标的：

| 标的类型 | 优先级 |
|---------|--------|
| 龙头股 | 最高 |
| 纯粹标的 | 高 |
| 影子股 | 中 |
| 多元化公司 | 低 |

### 第 5 步：证据质量评估

评估每个候选标的的证据质量：

| 证据等级 | 说明 |
|---------|------|
| 高 | 公司明确表述受益 |
| 中 | 行业趋势支持 |
| 低 | 仅概念相关 |

### 第 6 步：市场热度检查

检查当前市场热度：

| 热度 | 说明 |
|------|------|
| 高 | 大幅上涨、成交放量、社媒热议 |
| 中 | 温和上涨、正常成交 |
| 低 | 价格平稳、成交清淡 |

### 第 7 步：交易状态判断

综合以上信息，给出交易状态：

| 状态 | 条件 |
|------|------|
| Trade Ready | 证据强 + 结构好 + 未拥挤 |
| Watchlist | 证据强 + 结构待确认 |
| Wait Pullback | 证据强 + 但已上涨较多 |
| Research Only | 证据中等或弱 |
| Avoid | 证据不足或逻辑有缺陷 |
| Veto | 风控否决 |

## 输出格式

### 标准输出

| 主题 | 触发原因 | 受益链条 | 候选标的 | 证据等级 | 市场热度 | 交易状态 |
|------|----------|----------|----------|----------|----------|----------|
| AI 电力 | 数据中心耗电增长 | 电网、变压器、核能 | VST/GE/ETN | 中高 | 高 | Watchlist |
| RWA | 监管与机构采用 | 代币化资产、结算层 | ONDO/TRU | 中 | 中 | Research Only |

### 详细输出

对于每个值得关注的标的，输出简要说明：

```markdown
## [主题] - [标的]

**触发原因**: [催化剂描述]
**受益链条**: [产业链位置]
**证据**: [关键证据1, 关键证据2]
**市场热度**: [高/中/低] - [说明]
**交易状态**: [状态]
**后续动作**: [建议]
```

## 注意事项

1. **不预测未来**
   - 只识别当前可见的机会
   - 不预测"明天一定会涨"

2. **证据优先**
   - 没有证据的方向不推荐
   - 弱证据必须明确标注

3. **风险意识**
   - 高热度标的提醒拥挤风险
   - 大幅上涨标的提醒等待回踩

4. **持续跟踪**
   - Watchlist 标的需要定期检查
   - 新证据出现时更新状态
