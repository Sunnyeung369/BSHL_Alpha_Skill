# Crypto / Token — 人工研究框架

当前执行门控和现金回放仅验收 US/USD 股票/ETF 日线。Crypto 与 Token 可整理研究资料，当前卡片不得作为该市场真实 Trade Ready；本页不提供链上、交易所或下单连接。

## 研究清单

1. 区分网络、代币、公司与产品；核对链、合约地址、供给口径、解锁与资产权利。
2. 对用户、收入、费用、储备、治理和资金来源逐项保存 URL、日期、单位及可用时点。缺项记未知。
3. 区分真实使用和补贴激励、回购与代币持有人权益、协议收入与公司收入；保留反证。
4. 分析订单簿、集中度、托管、合约权限、跨链桥与监管风险；没有实时数据时不能猜测深度和持仓。
5. 输出带来源的研究假设、催化剂、失效条件、未核验项和 Research Only 状态。行业热度或高分不改变支持范围。

不得沿用股票营业时间、复权、整股单位与 USD 成本假设。独立适配应先定义 24/7 日界、报价币种、最小交易单位、费用/资金费率、停机和发布延迟，再用固定样本测试。
