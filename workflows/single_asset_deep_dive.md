# Single Asset Deep Dive
## 单标的深度分析工作流

---

## 工作流目的

对单个标的进行完整的六层分析，输出详细的分析卡。

---

## 输入格式

```
用 BSHL Alpha Skill 分析 [标的]
```

**示例标的：**
- NVDA（美股）
- 0700.HK（港股）
- ETH（Crypto）
- 某只股票的代码或名称

---

## 处理流程

### Layer 1: Universe Radar（标的识别）

**目的**: 确认标的的基本信息

**输出**:
```markdown
**标的**: [Ticker/Name]
**资产类别**: [美股/港股/A股/ETF/Crypto/Token]
**当前价格**: [价格]
**市值**: [市值]
```

---

### Layer 2: Alpha Thesis（投研假设）

**目的**: 判断逻辑是否成立

**必须回答的问题**:
1. 需求是否真实增加？
2. 供给是否短期受限？
3. 公司是否在卡点位置？
4. 客户是否愿意付费？
5. 收入是否可能兑现？
6. 毛利是否可能改善？
7. 估值是否仍有空间？
8. 催化剂是否临近？
9. 有无替代路线？
10. 市场是否已经讲烂了？

**输出结构**:
```markdown
**核心假设**: [一句话总结]
**需求驱动**: [需求分析]
**供给约束**: [供给分析]
**公司受益路径**: [如何受益]
**催化剂**: [催化剂]
**时间窗口**: [时间]
**估值错配**: [估值分析]
**最大风险**: [最大风险]
**结论等级**: [A/B/C/D]
```

---

### Layer 3: Evidence Ledger（证据账本）

**目的**: 结构化管理所有证据

**证据分类**:
- 强证据: 公司官方文件
- 中证据: 权威媒体报道
- 弱证据: 社媒讨论
- 过期证据: 已失效
- 待验证证据: 需要继续验证

**输出结构**:
```markdown
**强证据**:
- [证据1] (来源: XXX, 日期: XXX)
- [证据2]

**中证据**:
- [证据1]

**弱证据**:
- [证据1]

**过期证据**:
- [证据1]

**待验证证据**:
- [证据1]
```

---

### Layer 4: 反证矩阵

**目的**: 主动寻找可能错在哪里

**必须包含**:
- 最大反证
- 替代解释
- 一票否决证据
- 需要继续跟踪的问题

**输出结构**:
```markdown
**最大反证**: [为什么可能错了]
**替代解释**: [其他可能的解释]
**一票否决证据**: [什么情况下彻底错了]
**需要继续跟踪的问题**: [待验证问题]
```

---

### Layer 5: Market Regime（市场状态）

**目的**: 判断市场环境

**必须判断**:
- 大盘趋势
- 板块趋势
- 利率压力
- 美元流动性
- 风险偏好
- 资金宽度
- 主题拥挤度
- 期权情绪
- 空头结构
- 龙头股延续性

**输出结构**:
```markdown
**大盘**: [趋势]
**板块**: [相对强弱]
**资金**: [流入/流出]
**拥挤度**: [高/中/低]
**风险偏好**: [Risk On/Neutral/Risk Off]
**市场状态**: [整体判断]
```

---

### Layer 6: BSHL K线结构

**目的**: 确认交易时机

**必须检查**:
- 母周期方向
- 子周期位置
- 高低结构
- 突破是否有效
- 回踩是否健康
- 成交量是否确认
- 相对强弱是否跑赢
- ATR 波动是否过大
- 止损位是否清晰
- 盈亏比是否足够

**输出结构**:
```markdown
**母周期**: [方向]
**子周期**: [位置]
**关键高低点**: [高点/低点]
**支撑区**: [价位]
**压力区**: [价位]
**交易结构**: [结构状态]
**收盘确认状态**: [已确认/未确认]
**止损位**: [价位]
**盈亏比**: [比例]
```

---

### Layer 7: Risk Governor（风控总闸）

**目的**: 风险否决

**风险检查项（失败结果按[风控工作流](risk_governor_check.md)映射）**:
- [ ] 流动性不足
- [ ] 波动过大
- [ ] 证据质量太弱
- [ ] 社媒热度过度拥挤
- [ ] 财报前风险过高
- [ ] 重大监管不确定
- [ ] 个股已远离均值
- [ ] 止损距离过大
- [ ] 仓位暴露过高
- [ ] 相关资产集中度过高

**输出结构**:
```markdown
**流动性**: [充足/不足]
**波动**: [可控/过大]
**仓位**: [建议仓位]
**相关性**: [与其他持仓相关性]
**止损可执行性**: [清晰/模糊]
**最终风控结论**: [Pass/Reduce Size/Watch Only/Wait Confirmation/Wait/Veto]
```

## 注意事项

1. **证据溯源**
   - 每条证据必须标注来源和日期
   - 不确定的信息必须明确说明

2. **反证优先**
   - 必须主动寻找可能错在哪里
   - 不能只看支持性证据

3. **结构确认**
   - 没有收盘确认，不升级交易状态
   - 没有止损位，不进入执行准备

4. **风控否决**
   - Risk Governor 有最终否决权
   - 触发否决条件时明确说明
