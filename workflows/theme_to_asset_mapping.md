# Theme to Asset Mapping
## 主题到标的映射工作流

---

## 工作流目的

将一个主题或概念拆解成完整的产业链，识别每个环节的卡点，映射到对应的上市公司，并判断哪些标的值得研究。

---

## 输入格式

```
[主题] 这个主题里，哪些股票最值得研究？
```

**示例主题：**
- AI 电力短缺
- RWA 代币化
- 机器人供应链
- 核电复兴
- 半导体设备国产化

---

## 处理流程

### 第 1 步：主题定义

明确主题的核心问题和时间窗口。

```markdown
**主题**: [主题名称]
**核心问题**: [为什么这个问题现在重要]
**时间窗口**: [催化剂时间]
```

### 第 2 步：产业链拆解

将主题拆解成完整的产业链环节。

**拆解维度：**
1. **需求端**: 谁在需要？
2. **供给端**: 谁在提供？
3. **中间环节**: 有哪些卡点？
4. **最终用户**: 谁在买单？

**输出结构：**
```
┌─────────────────────────────────────────┐
│  需求端                                 │
│    ↓                                   │
│  中间环节 1 ─→ 卡点 A                  │
│    ↓                                   │
│  中间环节 2 ─→ 卡点 B                  │
│    ↓                                   │
│  供给端                                 │
└─────────────────────────────────────────┘
```

### 第 3 步：卡点识别

识别每个环节的关键卡点：

| 卡点类型 | 说明 | 示例 |
|---------|------|------|
| 产能受限 | 产能不足 | 晶圆厂产能紧张 |
| 技术壁垒 | 技术门槛高 | EUV 光刻机垄断 |
| 依赖进口 | 依赖外部 | 半导体材料依赖日本 |
| 认证周期 | 认证时间长 | 电网设备认证周期 |

### 第 4 步：公司映射

将每个卡点映射到具体的公司。

**映射原则：**
1. **龙头优先**: 行业龙头公司
2. **纯粹标的**: 业务纯粹的公司
3. **影子股谨慎**: 概念相关但实质有限

### 第 5 步：证据收集

收集每个映射公司的证据。

**证据来源：**
- 公司公告
- 财报电话会议
- 行业报告
- 新闻报道

### 第 6 步：评级判断

根据证据质量和受益确定性进行评级。

| 评级 | 条件 |
|------|------|
| A | 直接受益 + 强证据 |
| B | 间接受益 + 中证据 |
| C | 概念相关 + 弱证据 |

## 注意事项

1. **证据优先**
   - 没有公司映射到证据，不能推荐
   - 弱证据必须明确标注

2. **卡点优先**
   - 关注真正的卡点，而不是整个产业链
   - 卡点处的公司才有最大受益确定性

3. **龙头优先**
   - 优先推荐行业龙头
   - 小公司需要特别谨慎

4. **风险意识**
   - 明确标注每个标的的主要风险
   - 提醒板块热度，避免追高
