# Earnings Event Check
## 财报前后检查工作流

---

## 工作流目的

财报是美股和币股联动里最容易杀人的节点。本工作流用于判断财报前后的交易策略。

---

## 财报前检查

### 必须检查的维度

| 维度 | 检查点 | 高风险信号 |
|------|--------|-----------|
| 市场预期 | 分析师一致预期 | 预期过高 |
| 期权隐含 | 隐含波动率 | IV > 历史均值 2 倍 |
| 价格反应 | 股价已反应程度 | 财报前涨幅 > 10% |
| 核心变量 | 收入 vs 指引 | 哪个更关键 |
| 毛利率 | 是否是核心变量 | 毛利率趋势 |
| 管理层 | 措辞变化 | 转鹰派或转谨慎 |
| 期权结构 | Call/Put 比率 | 过度偏多 |

### 财报前状态

| 状态 | 条件 | 建议 |
|------|------|------|
| Pre Earnings High Risk | IV 过高 + 预期过高 + 已大涨 | 财报前不追，可轻度对冲 |
| Pre Earnings Moderate | IV 正常 + 预期合理 | 可持有，不加仓 |
| Pre Earnings Low Risk | IV 低 + 预期低 + 未大涨 | 风险可控 |

---

## 财报后检查

### 必须检查的维度

| 维度 | 检查点 | 反应 |
|------|--------|------|
| 财报结果 | 超预期/符合/不及预期 | - |
| 指引变化 | 上调/维持/下调 | - |
| 盘后反应 | 盘后涨跌幅 | - |
| 缺口 | 是否形成缺口 | - |
| 成交量 | 是否放量 | - |
| 趋势 | 趋势延续/反转 | - |

### 财报后状态

| 状态 | 条件 | 建议 |
|------|------|------|
| Post Earnings Gap Hold | 超预期 + 缺口 + 放量 | 等缺口确认 |
| Guidance Breakout | 指引大幅上调 + 股价突破 | 观察趋势延续 |
| Sell The News | 超预期但高开低走 | 避免追高 |
| Earnings Disappointment | 不及预期 + 跌破关键位 | 等待企稳 |

## 示例

### 财报前检查

**输入**: 检查 NVDA 财报前的状态

**输出**:
```
## 财报前检查 - NVDA

**财报日期**: 2026-05-22
**当前价格**: $1,200
**距离财报**: 3 天

---

### 市场预期
**一致预期 EPS**: $5.20
**一致预期收入**: $26B
**预期合理性**: 偏高 - 近期上调多次

### 期权隐含
**隐含波动率**: 45%
**IV vs 历史均值**: 1.8 倍
**风险**: 中高

### 价格反应
**财报前涨幅**: +8% (1 个月)
**是否已反应**: 部分反应

### 核心变量
**关键变量**: 数据中心收入增长
**理由**: 市场最关注 AI 相关收入增速

### 管理层措辞
**上次措辞**: 乐观，强调 AI 需求强劲
**措辞趋势**: 稳定偏鸽

### 期权结构
**Call/Put 比率**: 1.6
**情绪**: 偏多但未极端

---

### 综合判断

**财报前状态**: Moderate

**建议**:
- 可持有现有仓位，不建议加仓
- 如持有，可考虑轻度对冲 (买入 Put)
- 等财报后再决定是否加仓

**风险提示**:
- 数据中心收入增速可能不及预期
- 期权成本较高，对冲需谨慎
```

### 财报后检查

**输入**: 检查 NVDA 财报后的状态

**输出**:
```
## 财报后检查 - NVDA

**财报日期**: 2026-05-22
**盘前价格**: $1,200
**盘后价格**: $1,260
**涨跌幅**: +5%

---

### 财报结果
**EPS**: $5.35 vs $5.20 (超预期)
**收入**: $26.5B vs $26B (超预期)
**指引**: 上调

### 盘后反应
**盘后涨跌**: +5%
**是否形成缺口**: 是
**缺口大小**: $60 (5%)

### 成交量
**盘后成交量**: 高于正常 2 倍

### 趋势判断
**趋势**: 延续
**支撑/压力**: 支撑 $1,200，压力 $1,300

---

### 财报后状态

**状态**: Post Earnings Gap Hold

**建议**:
- 等待明日开盘确认缺口是否有效
- 如开盘站稳 $1,240+，可考虑加仓
- 如开盘回补缺口，等待回踩确认

**后续观察**:
- 缺口是否在 3 日内回补
- 成交量是否持续
- 管理层后续发言
```

## 注意事项

1. **财报前风险**
   - IV 过高时不宜裸卖期权
   - 预期过高时财报容易"Sell The News"

2. **财报后确认**
   - 盘后反应不一定等于次日开盘
   - 等待开盘确认再决策

3. **核心变量识别**
   - 不同公司核心变量不同
   - 识别正确才能准确判断

4. **缺口确认**
   - 大部分缺口会在 3 日内回补
   - 等待确认更安全
