# Trade Readiness Check
## 交易准备检查工作流

---

## 工作流目的

判断一个标的现在是否具备交易准备条件，特别是已经涨了一段的情况下。

---

## 输入格式

```
这个标的已经涨了 [X]%，还能不能追？
```

或

```
检查 [标的] 的交易准备状态
```

---

## 处理流程

### 第 1 步：定价状态检查

**问题**: 市场是否已经定价了这个逻辑？

**检查维度**:
| 维度 | 检查点 | 已定价信号 |
|------|--------|-----------|
| 价格 | 相对关键点位的位置 | 远离支撑区 |
| 涨幅 | 近期涨幅 | 3个月涨幅 > 50% |
| 估值 | 相对历史估值 | PE/PB 超过历史均值 2 倍 |
| 预期 | 市场预期 | 一致预期已经很高 |

---

### 第 2 步：拥挤度检查

**问题**: 是否有太多人在这个交易上？

**检查维度**:
| 维度 | 检查点 | 拥挤信号 |
|------|--------|---------|
| 成交量 | 相对历史成交量 | 持续高于历史均值 2 倍 |
| 社媒 | 讨论热度 | 社媒讨论量激增 |
| 期权 | 看涨情绪 | Call/Put 比率异常高 |
| 资金 | 资金流入 | 短期大量资金流入 |

---

### 第 3 步：K线结构检查

**问题**: 当前位置是否合理入场？

**检查维度**:
| 维度 | 检查点 | 不利信号 |
|------|--------|---------|
| 母周期 | 是否顺应大趋势 | 逆势 |
| 子周期 | 当前位置 | 远离合理入场区 |
| 支撑 | 距离支撑位 | 距离 > 2 倍 ATR |
| 止损 | 止损位是否清晰 | 止损距离过大 |

---

### 第 4 步：风控检查

**问题**: 风控是否允许？

**一票否决条件**:
- [ ] 流动性不足
- [ ] 波动过大
- [ ] 证据质量太弱
- [ ] 社媒热度过度拥挤
- [ ] 财报前风险过高
- [ ] 重大监管不确定
- [ ] 个股已远离均值
- [ ] 止损距离过大
- [ ] 仓位暴露过高
- [ ] 相关资产集中度过高

---

---

## 输出状态与建议

| 状态 | 条件 | 建议 |
|------|------|------|
| Trade Ready | 定价合理 + 结构健康 + 未拥挤 + 风控通过 | 可进入执行准备 |
| Watch Closely | 定价合理 + 结构待确认 + 未拥挤 + 风控通过 | 密切观察 |
| Wait | 定价偏高或拥挤度上升 | 等待回踩 |
| No Trade | 定价过高或过度拥挤 | 不建议入场 |

## 示例

### 输入
```
NVDA 已经涨了 40%，还能不能追？
```

### 输出
```
## 交易准备检查 - NVDA

**日期**: 2026-06-06
**当前价格**: $1,200
**近期涨幅**: +42% (3个月)

---

### 一、定价状态
**判断**: 部分定价
**分析**:
- 价格位置: 接近历史高点，距离 200 日均线 +15%
- 涨幅分析: 3个月涨幅 42%，高于历史正常范围 (20-30%)
- 估值分析: Forward PE 35x，高于 5 年均值 28x
- 预期分析: 市场对 AI 数据中心需求预期已较高

### 二、拥挤度
**判断**: 适中
**分析**:
- 成交量: 近期成交量放大，但未极端
- 社媒: 讨论热度高，符合龙头地位
- 期权: Call/Put 比率 1.5，偏多但未极端
- 资金: 机构资金持续流入

### 三、K线结构
**判断**: 远离合理入场区
**分析**:
- 母周期: 周期级别上涨趋势
- 子周期: 日级别加速上涨
- 支撑位: $1,050 (近期平台)
- 当前位置: 距离支撑约 12.5% (价1,200、支撑1,050、ATR约60，约2.5倍ATR)
- 止损位: $1,050 附近，相对清晰

### 四、风控检查
**触发否决**: 否
**检查项**:
- [x] 流动性充足 (日成交 > $30B)
- [x] 波动可控 (ATR 约 5%)
- [x] 证据质量强
- [x] 社媒热度适中
- [x] 无财报风险 (财报后)
- [x] 监管确定
- [x] 止损距离合理
- [ ] 相关性需检查 (与现有持仓)

### 五、综合判断
**研究价值**: 高
**交易状态**: Wait
**Risk Governor**: Watch Only

### 六、行动建议
**建议动作**: 加入观察池，等待回踩确认

**观察条件**:
- 回踩至 $1,050-$1,100 区间
- 成交量萎缩后重新放大
- 新平台构筑完成

**放弃条件**:
- 跌破 $1,000 且放量
- 证据链失效 (AI 需求减弱)
- 市场进入 Risk Off

**失效条件**:
- 本判断失效时间: 2 周
- 如价格突破 $1,300，需重新评估
```

---

## 注意事项

1. **不预测未来**
   - 只判断当前状态
   - 不预测"一定会涨到 XX"

2. **风险优先**
   - 宁可错过，不做错
   - 拥挤度上升时主动降级

3. **结构确认**
   - 没有好的入场位，即使逻辑好也不追
   - 等待回踩是合理策略

4. **持续跟踪**
   - 状态是动态的
   - 定期重新评估
